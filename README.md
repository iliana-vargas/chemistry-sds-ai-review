# chemistry-sds-ai-review

## Overview
This case study evaluates AI-generated Safety Data Sheet (SDS) content 
against GHS/OSHA 2012 standards and real-world chemistry expert knowledge.

## Methodology
Each case presents an AI-generated SDS section alongside:
1. Expert identification of errors
2. Classification of error type (factual, regulatory, safety-critical)
3. Corrected version with annotation rationale
4. Severity score (1-5 scale)

## Error Categories Identified
- GHS Hazard Misclassification (e.g., wrong pictogram, signal word)
- Missing or Incorrect Exposure Limits (OSHA PEL / ACGIH TLV)
- Incomplete PPE Guidance
- Incorrect First Aid Procedures
- Faulty Disposal / Environmental Sections

## Why This Matters for AI
SDS errors in AI-generated chemistry content can cause real-world harm. 
This project demonstrates the value of expert annotation in chemistry AI 
data pipelines and the author's qualifications to provide it.
